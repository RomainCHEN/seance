Séance · Kiroween 2026

Multi-agent rooms you can actually reproduce.

Séance is a template for the part of multi-agent apps nobody wants to rewrite: personas in YAML, a pure seeded engine that turns an artifact into a transcript, and a room UI that renders any transcript. No API key, no network call, same input → same output, every time.

Make your own room in three steps

  1. npm run new-room -- my-room
  2. Write apps/my-room/personas/*.yaml — id, name, role, order, voice, lenses, phrases.
  3. npm run dev -w apps/my-room

Everything the engine needs is data. If a new room requires editing @seance/core, the template has a bug — fix the template, not the app.
