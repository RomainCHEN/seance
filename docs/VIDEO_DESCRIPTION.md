#KiroweenHackathon26

Séance is a skeleton template for multi-agent "rooms": personas live in YAML, a pure seeded
engine turns an artifact into a transcript, and one reusable React shell renders it. Because the
engine is pure, the same artifact and seed always produce the same transcript — so the demo runs
with no API key, no network call and no tokens, and a recording can never drift from the site.

Two apps are built from the template without touching the engine:
• Code Séance — three reviewers read a diff and return a merge verdict.
• Postmortem Séance — three investigators read an incident timeline and return a root-cause
  verdict.

Try it: https://romain.is-a.dev/seance/
Source: https://github.com/RomainCHEN/seance
